# Pentomino Puzzle

12 種のペントミノを、盤に隙間なく敷き詰めるパズルです。ブラウザだけで遊べます。

### ▶ [いますぐ遊ぶ](https://ytani01.github.io/pentomino-puzzle/)

インストールも登録も要りません。パソコンでもスマホでも、マウスでもタッチでも遊べます。

[![デモ。コンピューターがピースを置いたり外したりしながら解を探します（押すとデモが開きます）](docs/images/demo.gif)](https://ytani01.github.io/pentomino-puzzle/?demo=random&board=8x8)

## 遊び方

右のトレイからピースを左の盤へドラッグして置きます。ピースをタップすると
向きが変わります（回転と裏返し）。12 枚すべてを隙間なく置けば完成です。

- 置く場所は多少ずれていても、近くの置けるマスへ吸い付きます
- 盤は **8×8**（中央に穴）と **6×10** の 2 つです。解は 8×8 が 65 通り、
  6×10 が 2339 通りです（回転・反転で同じものは 1 つと数えます）
- 詰まったら **ヒント表示** で「まだ解けるか」が分かり、**おまかせ** で
  1 枚ずつ置いてもらえます。どちらも待たされません
- クリアすると、それが何番目の解かが出ます。見つけた解と最短時間は記録に残り、
  全解のうちいくつ見つけたかを見返せます
- 途中でやめても、次は **つづきから** 再開できます

## デモ

コンピューターがピースを置いては外しながら、解を探し当てる様子を眺められます
（上の画像を押すと、デモが直接開きます）。
