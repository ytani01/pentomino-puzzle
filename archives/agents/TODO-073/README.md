# TODO-073 の分担

Sonnet 5 が週の利用上限で使えないので、TODO-071 のときの利用者の判断どおり全員 Opus 5.5 にした。

- implementer（Opus 5.5）: 記録画面の「この回を続ける」、履歴の 1 件から遊びかけの形を作る計算とテスト、遊びかけがあるときの確認、`tools/capture.mjs`。
  reviewer の指摘（「はじめる」が前の続きを引き継ぐ不具合、注記、`placementIn()` への置き換え）も同じ担当に続けて頼んだ
- docs（Opus 5.5）: implementer は文書を触らないので、文書を別の担当にした（TODO-072 の振り返りどおり最初から立てた）
- reviewer（Opus 5.5）: 画面の移り方と遊びかけの扱いが変わるのでレビューを入れた。「はじめる」の不具合を実測で見つけた
- verifier（Opus 5.5）: Playwright で 7 項目を 1 回ずつ（自分で組んだスクリプト）。記録画面を横・縦で撮った
- main: 利用者への確認（ボタンの置き方）、依頼の組み立て

screens は立てず、verifier が撮った画像を main が見た。
依頼は `*-brief.md`、報告は `*-report.md`（2 回目以降は同じファイルに追記）。
