# TODO-070 implementer への依頼（1 回目: 案を描く）

## 目的

デモの探し方のボタンのアイコン（`src/icons.js` の `depthFirst`・`random`）を、「機械的に決まった順番で埋める」と
「人らしく試行錯誤する」が対になる絵に描き直す。今は縦に並んだ点とサイコロで、違いが分かりにくい（利用者の指摘）。
ボタンは押すと切り替わり、今の探し方を出す。この作りは変えない。仕様の背景は `TODO.md` の TODO-070 の節。

## やること

1. `src/icons.js` に、対になる案を 3 組、仮の名前で足す（例 `depthFirstA`・`randomA` 〜 `C`）。Graphics API の線画で、
   今のアイコンと同じ大きさの単位 `U`・`begin()` を使う。案の例（これに縛られなくてよい）:
   - A: 3×3 の格子を左上から順に矢印でたどる／同じ格子に点がばらばらに散る
   - B: 番号順の階段（1→2→3）／曲がりくねった線（迷いながら進む）
   - C: 歯車（機械）／頭に「?」の吹き出し（人が考える）
   どの組も、ほかの HUD のアイコン（速さの三角、虫眼鏡、ミュート、ホーム）と取り違えない形にする
2. 撮る担当が案を差し替えられるよう、どうやって差し替えるか（`evaluate` で `strategyButton.setIcon(ICONS.depthFirstA)` など）を報告に書く
3. 今の `depthFirst`・`random` は消さない（案を選んだあとに差し替える）

## 保つもの

- アイコン以外は変えない。規約（色は `config.js`、Graphics API で描く、画像を足さない）
