# TODO-044 forcedPlacements() のテスト（tests.html）

`tests.html` に「src/logic.js — forcedPlacements」の節を足した。
8×8・6×10 の両方で、`boardStates`（解 1 つを組み立てた盤）を使って回す。

## 足したテスト（各盤 1 件、計 10 件）

- 取り除いた 1 つのピースだけを返し、置き直すと元の盤に戻る
- names に無いピースの形の空きは返さない
- 隣り合わない 2 つを取り除くと両方返し、隣り合う 2 つは何も返さない
- 同じピースの形の空きが 2 か所にあっても 1 回だけ返す
- 空の盤では何も返さない

## 結果

`tests.html` 全体で **266 件すべて通った**（追加前は 256 件）。

## 壊すと落ちるか（`src/logic.js` を一時的に壊して確認、都度元に戻した）

| 壊し方 | 落ちた件数 | 落ちたテスト |
|---|---|---|
| `row`/`col` の計算に `+ 1`（座標を 1 ずらす） | 4 件 | 「1 つのピースだけを返し…戻る」（8×8・6×10）、「隣り合わない 2 つ…」（8×8・6×10） |
| 空き領域の大きさ判定 `region.length !== PIECE_SIZE` を無効化 | 0 件 | なし（`sameShape` が長さ違いで自然に不一致になるため、この壊し方では検出できなかった） |
| 重複除外 `!found.some(...)` を外す（同じピースを 2 回返せるようにする） | 2 件 | 「同じピースの形の空きが 2 か所にあっても 1 回だけ返す」（8×8・6×10） |
| `names` によるフィルタ `.filter((piece) => names.includes(piece.name))` を外す | 2 件 | 「names に無いピースの形の空きは返さない」（8×8・6×10） |

いずれも壊した後、`tests.html` の該当節の import に一時的な
`?bust=N` を付けてブラウザの HTTP キャッシュを避けて再読み込みし、
壊れたことを確認した（確認後は import 行も元に戻した）。

壊した後は `src/logic.js` を毎回元に戻し、最終的に
`git diff src/logic.js` が作業開始時と一致することを確認済み
（`src/logic.js` は今回の作業で 1 文字も変えていない）。

## 判断が要る点

- 「大きさ判定を外す」壊し方は、今回のテスト群では検出できなかった
  （`sameShape` が長さの違いで先に弾くため、実害は未確認）。
  もし大きさ判定そのものを壊すケースを検出したいなら、5 マス以外の
  大きさの領域を作ってピースの形と偶然一致させる必要があり、
  そのためのテストを追加するかどうかは判断が要る。
