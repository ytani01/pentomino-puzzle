# TODO-042 implementer への依頼

## 目的

本編とデモの HUD のボタン（`GameScene.createHudButtons()` を通る 12 種）を、
文字からアイコンに替える。マウスでホバーしたら説明を出し、タッチ端末では
押したとき（動作はそのまま）に説明を少しの間だけ出す。

決まっていること（利用者と決めた。変えない）:

- アイコンは **Graphics API で描く**。Unicode の記号・絵文字・画像アセットは使わない
- デモの HUD も含める
- タッチでは、押すと動作し、同時に説明を短く出す（長押しにしない。手数を変えない）

## 対象

```bash
rg -n "createHudButtons|createButton|setLabel|音 ON|音 OFF|muteButton" src
rg -n "一手戻す|おまかせ|ヒント表示|やり直し|音の ON|次の解を探す|ゆっくり|最速|タイトルへ" README.md docs/developer.md CLAUDE.md
```

## 設計（main が決めた。迷ったら報告に書いて、この形で進める）

1. **`createButton()`（`src/ui.js`）に `icon` と `tooltip` の 2 つを足す。**
   - `icon` は `(graphics, color) => void` の描画関数。渡されたら文字の代わりに
     ボタン中央へ描く。**色はボタンの状態（通常・押せない・選んである）に
     連れていく**（今の `redraw()` が文字色を変えているのと同じ規則。
     Graphics には数値の色が要るので、`TEXT_COLORS` に対応する数値の色が
     `COLORS` に無ければ `config.js` に足す。色をコードへ直接書かない）
   - `setIcon(fn)` を生やす（音の ON/OFF の切り替えで使う）。`setLabel` は残す
     （タイトル・記録・クリアの文字のボタンはそのまま動くこと）
   - `tooltip` は説明の文字列。`setTooltip(text)` も生やす
2. **アイコンは新しい `src/icons.js` に置く**（12 種ぶんの描画は `ui.js` に
   入れると長くなるため）。ピースの見た目には依らない線画にする。
   形の案（見分けやすさ優先で変えてよい）:
   一手戻す＝左向きに曲がった矢印 / おまかせ＝魔法の杖か星のきらめき /
   ヒント表示＝電球 / やり直し＝円を描く矢印 / 音 ON＝スピーカーと波 /
   音 OFF＝スピーカーと × / タイトルへ＝家 / ゆっくり・速い・最速＝右向きの
   三角 1・2・3 個 / 次の解を探す＝虫眼鏡か「▶|」
   一手戻すとやり直しは形が似やすいので、並べて見分けがつくようにする
3. **説明（ツールチップ）は 1 シーンに 1 つだけ作り、シーンのプロパティに持つ**
   （モジュールのトップレベルに状態を置かない。`CLAUDE.md` の規約）。
   ボタンの下に出す（HUD は画面の上端なので）。左右は画面（`SCREEN`）の内側に
   収める。depth は HUD・ドラッグ中のピースより上、確認の表示（`DEPTH.confirm`）より下
4. **マウスとタッチの見分けは `pointer.wasTouch`**（`game.js` のドラッグと同じ）。
   - マウス: `pointerover` で出す（少し待ってから出すなら `scene.time.delayedCall`）。
     `pointerout` と `pointerdown` で消す
   - タッチ: `pointerover` では出さない（Phaser はタッチでも over を出すため）。
     `pointerup` で動作させたあと、説明を一定時間出して消す
   - 遅延と表示時間は `scene.time.delayedCall()` で。**`setTimeout` を使わない**。
     数値（待ち時間・表示時間・余白・文字の大きさ）は `config.js` に置く
5. **説明の文言は今のラベル**（'一手戻す' 'おまかせ' 'ヒント表示' 'やり直し'
   'タイトルへ' 'ゆっくり' '速い' '最速' '次の解を探す'）。音は状態に合わせて
   '音 ON' / '音 OFF'（今の `setLabel` の代わりに `setIcon` と `setTooltip` を呼ぶ）
6. 押せないボタン（`setEnabled(false)`）でも、マウスのホバーでは説明を出す
   （なぜ押せないか分からなくても、何のボタンかは分かるように）。タッチで
   押せないボタンを押したときも出してよい
