# TODO-063 tests への依頼

## 背景

`solveStepsRandom()` に「同じ深さで行き詰まりが続いたら数手まとめて崩す」を足した（`git diff src/logic.js src/config.js`）。
利用者が決めたこと: 行き詰まり（置ける手が尽きて戻った一続き）が終わったときの `stack.length` ごとに回数を数え、
`DEMO.randomCollapseAfter`（仮 5）に達したら `DEMO.randomCollapseMoves`（仮 3）手を続けて外す。崩した手は全部控え `failed` に入れる。
置いた直後にその場で外す手（TODO-060/068・066・067）は数えない。崩したら崩した後の深さ以上の回数を消す。
実装担当の報告（「追記 2」が最新。落ちた既存 2 件）: `archives/agents/TODO-063/implementer-report.md`。

## やること

1. **落ちた既存 2 件を直す**（「外す連なりが ok:true で止まったとき…次は必ず place」8×8・6×10）。崩しが連なりの末尾に続く remove を
   足すのは仕様どおり。崩しの remove を見分けて不変条件から除く（崩しの直後の見分け方はテスト側で深さごとの回数を再現するなど）。
   元の狙いは弱めない
2. **足す**:
   - 崩しが起きること、1 回の崩しで外す手数が `randomCollapseMoves`（盤に残る手がそれより少なければその数）であること
   - 同じ深さの行き詰まりが `randomCollapseAfter` 回目のときだけ崩す（その場で外す手は数えない）こと
   - 崩した手が控えに入り、崩した先の盤面で同じ手を選び直さないこと
   テストで値を変えるなら `DEMO` を finally で戻す。場面を集めるテストは、見つけても打ち切らず全部確かめる
3. 壊すと落ちるか: (a) 崩しを消す、(b) その場で外す手も数える、(c) 崩した手を控えに入れない、のそれぞれで何かが落ちることを
   Node で確かめて戻す
4. シードの組を 10 通りずらしても通ることを Node で確かめる。手数は増やさない。1 件 1 秒以内
