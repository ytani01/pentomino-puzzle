# TODO-079 の分担

## 分担と理由

| 担当 | モデル | 範囲 |
|------|--------|------|
| implementer-1 | Opus 5.5 | `src/logic.js`・`src/solutions.js`・`src/config.js` |
| implementer-2 | Opus 5.5 | `src/scenes/game.js`・`src/scenes/demo.js`・`src/scenes/records.js` |
| implementer-3 | Opus 5.5 | 上以外の `src/`（`src/data/` を除く）と `tools/*.mjs` |
| reviewer | Opus 5.5 | 3 人の差分すべて |
| verifier | Sonnet 5 | 3 人の差分すべて（reviewer の指摘を反映した後） |

- コメント行が約 2,100 行あり、1 人では長いので 3 つに分けた。行数がおおよそ揃うように分けた
- 日本語の良し悪しと「意味が変わっていないか」の判断が要るので、実装とレビューは Opus
- verifier は「差分がコメントだけか」「テストが通るか」の機械的な確認なので Sonnet

## implementer への依頼（共通）

目的: 担当ファイルのコメント（`//`・`/* */`・JSDoc）を、分かりやすく端的で自然な日本語に直す。

- 直すもの: 冗長な言い回し、直訳調、要らない主語、同じことの繰り返し、回りくどい言い方
- 残すもの:
  - `（TODO-NNN）` の番号参照
  - 「なぜそうするのか」の説明（`CLAUDE.md` の JSDoc の規約）。短くしてよいが消さない
  - 関数名・変数名・Phaser の API 名などのコード参照（バッククォートも含めて）
  - 区切りのコメント（`// ---- 画面の組み立て ----` など）
- 削るもの:
  - 経緯（「TODO-069 レビューの要修正 4」「以前は〜だったが」など）。番号だけ残して経緯は archives に任せる
  - 中身が無くなったコメント（コードを読めば分かる「何をするか」だけのもの）
- **コードは 1 文字も変えない。** 文字列リテラル（画面に出る文言を含む）も変えない。
  インデントや空行の位置も、コメントを削った分以外は変えない
- 他の担当のファイルには触れない。コミットしない
- 完了条件: 担当ファイルを直し終え、`node --check <file>` が通る
  （`src/` は ES Modules なので `node --input-type=module --check < file` か、拡張子に合わせて確かめる）
- 報告: `archives/agents/TODO-079/<担当名>-report.md` に「ファイルごとの直した件数」
  「消したコメントのうち判断に迷ったもの（行番号と理由）」だけを書く。
  返事は「終わったか・報告ファイルのパス・判断が要る点」の 5 行以内
