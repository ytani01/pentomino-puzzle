# TODO-037. 使い回せるサブエージェントの定義を置く

## きっかけ

規模の大きい項目ではサブエージェントに分担させてきたが、起動するたびに
指示をその場で書いていた（`archives/agents/TODO-008` ・ `TODO-009`）。
同じことを毎回書き直すのをやめ、繰り返し出てくる役割を
`.claude/agents/*.md` に置いて使い回せるようにした。

## やったこと

`archives/todo/` の 36 件を読み、繰り返し出てきた役割を 4 つにまとめた。

| 定義 | モデル / effort | 受け持ち |
|---|---|---|
| `.claude/agents/tests.md` | Sonnet / medium | `tests.html` にテストを足して走らせる |
| `.claude/agents/screens.md` | Sonnet / low | 画面を撮って、はみ出し・重なり・読めない文字を見る |
| `.claude/agents/docs.md` | Sonnet / medium | 文書を今のコードに合わせる |
| `.claude/agents/measure.md` | Sonnet / medium | 回数・時間・大きさを実測して表にする |

どれにも次の 3 つを書いた。

- 触ってよいファイルの範囲（範囲外には手を出さない）
- ツール呼び出しの上限回数（超えたら止めて報告する）
- 出力を書き出す直前に、拠り所となる仕様のファイルを読み直すこと

一覧は [docs/developer.md の「サブエージェントの定義」](../../docs/developer.md#サブエージェントの定義)
に載せた。`CLAUDE.md` のファイル構成の表からも辿れる。

**`archives/agents/TODO-037/` は作っていない。** この項目は定義そのものを
作るもので、現物は `.claude/agents/` に現行の設定として残るため
（過去の 1 回きりの分担は今までどおり `archives/agents/` にある）。

## テスト

4 つとも実際に起動して確かめた（2026-08-18）。書き換えの受け持ちを持つ
`tests` と `docs` には「直す直前まで」と伝え、作業ツリーを変えずに見た。

| 担当 | 結果 | ツール呼び出し |
|---|---|---|
| `measure` | 向きの数 63、解 65 / 2339、正規化の所要時間を計測 | 11 / 上限 50 |
| `screens` | 4 枚撮影、はみ出し・重なり無し、コンソールのエラー 0 件 | 26 / 上限 40 |
| `docs` | 食い違い 0 件 | 28 / 上限 40 |
| `tests` | 依頼の 2 項目は既存テストにあると判明、235 件すべて通過 | 11 / 上限 60 |

4 つとも受け持ち外のファイルには手を出さなかった。`tests` が「依頼された
2 項目は既にある。足すかどうかは呼ぶ側が決める」と差し戻したのも、
定義したとおりの動きだった。

**`screens.md` の画像の保存先が間違っていたので直した。** 当初は
`~/tmp/claude-img/` に書くと決めていたが、Playwright MCP が書けるのは
`--output-dir` の `~/tmp/playwright-mcp` とリポジトリの 2 つだけで、
外を指すと `File access denied: outside allowed roots` で失敗する。
保存先を `~/tmp/playwright-mcp/` の直下に改め（`imv` でまとめて開けるよう
サブディレクトリは作らない）、利用者の `~/.claude/CLAUDE.md` の
「画像の見せ方」節も同じ場所に揃えた。
