# TODO-003. プレイ中にタイトル画面へ戻れるようにする

## きっかけ

「プレイ中に中断してタイトル画面に戻りたいときはどうすればいい？」という質問から、
そもそもその手段が無いことが分かった。ボタンは「一手戻す・ヒント・やり直し・
音の ON/OFF」だけで、タイトルへの遷移はクリア画面にしかなかった。

## やったこと

モデルは Sonnet / effort low。ファイル 2 つ（`src/config.js` / `src/scenes/game.js`）
への追加で、既存の `createButton` / `createPanel` を組み合わせるだけの範囲なので、
サブエージェントは編成しなかった。

- `src/config.js` の `LAYOUT` に `confirm`（確認ダイアログの位置・大きさ）を追加
- `src/scenes/game.js` の HUD に「タイトルへ」ボタンを追加
- クリックすると、画面中央に確認ダイアログ（「タイトルへ戻りますか？
  今の進み方は失われます」＋「戻る」「やめる」）を出す。「戻る」で
  `Title` シーンへ、「やめる」でダイアログを閉じて本編に留まる
- ダイアログの背景に画面全体を覆う当たり判定を持たせ、開いている間は
  ピースやほかのボタンへクリックが抜けないようにした（Phaser の入力は
  既定で最前面の対象だけに配る `topOnly` なので、これで足りる）

### 決めたこと

- 確認手段にブラウザネイティブの `confirm()` を使わない方針にした
  （理由は `CLAUDE.md` の規約に書いた。この項目がきっかけで決めた方針）

## テスト

- `node --check` で `src/config.js` / `src/scenes/game.js` / `src/ui.js` の構文を確認
- ローカルサーバ（`python3 -m http.server 8765`）を立て、Playwright（この環境に
  無かったので Chromium を一時的に導入して確認した）でタイトル → 本編 →
  「タイトルへ」→ 確認ダイアログ表示 → 「やめる」で本編に留まる →
  再度「タイトルへ」→「戻る」で `Title` シーンへ遷移、の一連をスクリーンショットと
  シーンの状態（`window.game.scene.getScenes(true)`）で確認した
