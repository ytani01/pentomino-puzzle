# TODO-027. 記録一覧の印を右端へ揃える

## きっかけ

TODO-024 で履歴にヒント・詰み表示の使用が残るようになり、一覧へ出すと
**印の有無で文字列の長さが変わる**。行は中央寄せだったので、そのままだと
日時や時間の位置が行ごとにずれて読みにくい。

## やったこと

### ボタンに左寄せと印を足した

`ui.js` の `createButton` に `align`（`'center'` / `'left'`）と `mark` を
足し、`setMark()` を生やした。

- `align: 'left'` … ラベルを左端から `BUTTON_PAD`（14）だけ空けて左寄せ
- `mark` … 右端から同じだけ空けて右寄せ。大きさはラベルの 0.85 倍
  （行の主役は日時と時間なので、印は 1 段落として出す）
- 選んだ行では**印も強調色へ連動**させる。印だけ地の色のまま残ると、
  その行が選ばれていることが伝わりにくい

記録の一覧の行だけがこれを使う。ほかのボタンは今までどおり中央寄せ。

### 印は短い言葉にした（決めることの答え）

`「ヒント」`「`詰み`」で、両方なら `「ヒント・詰み」`。

**記号やアイコンにしなかった**のは、凡例を別に置かなくても意味が分かる
ようにするため。1 文字（「ヒ」「詰」）へ縮めれば横幅は空くが、それが何を
指すかはこの画面のどこにも書かれていないことになる。

TODO-026 で文字を大きくしたあとでも、**一番狭い横画面の行（432）**に
日時・時間・「ヒント・詰み」が収まることを確かめてある。

### 選んだ 1 件の見出しにも添えた

行の印は一覧を見渡すためのもので、見出しの印は「今どの回を見ているか」の
確認になるので、両方に出す。見出しは 2 行に分けた
（1 行では完成形の枠より横にはみ出す。TODO-026）。

```
2026/08/16 15:31　00:02
46 番　（ヒント・詰み）
```

## テスト

見た目の話なので `tests.html` には足していない（192 件が通ることだけ
確かめた）。headless の Chromium で、印のある行と無い行が混ざった一覧を
横画面 568×320 と縦画面 390×844 で撮り、日時が行ごとにずれないこと、
選んだ行の印が強調色になることを確かめた。
