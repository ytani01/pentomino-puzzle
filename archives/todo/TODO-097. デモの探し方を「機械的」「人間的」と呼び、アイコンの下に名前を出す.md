# TODO-097. デモの探し方を「機械的」「人間的」と呼び、アイコンの下に名前を出す

|      | main | 担当 |
|------|------|------|
| 見込み | Opus 5.5 / effort 記載なし | main（実装）+ screens（Sonnet 5 / low） |
| 実施 | Opus 5.5 / effort 記載なし | main（実装）+ screens（Sonnet 5 / low） |

| 担当 | モデル | effort | output | cache_creation | 料金の割合 |
|------|--------|--------|--------|----------------|-----------|
| main | Opus 5.5 | 記載なし | 7,500 | 27,249 | 78% |
| screens | Sonnet 5 | low | 448 | 48,582 | 22% |
| 合計 |  |  | 7,948 | 75,831 | 概算 $1.5 |

- screens は定義のモデル（sonnet）・effort（low）のまま動かした
- main の effort は指定していない

## きっかけ

デモの探し方の呼び方「深さ優先」「ランダム」は、アルゴリズムの用語で一般の
プレーヤーに通じにくい。深さ優先は機械的に、ランダムは人間っぽく動くように
作ってあるので（TODO-059・TODO-065）、その違いを呼び方に出したい。
字数を揃えて「機械的」「人間的」にし、アイコンの絵はそのままで下に小さく
名前を出す（小さくて読みにくくてもよい）と利用者が決めた。

## やったこと

- `src/ui.js` の `createButton()` に `caption` を足した。渡すとアイコンを上へ
  ずらし、ボタンの下端に小さく名前を出す。色は文字と同じ規則で変える。
  `setCaption()` で差し替えられる
- `src/config.js` の `ICON` に `captionSize`（12）と `captionShift`（6）を足した
- `src/scenes/game.js` の `createHudButtons()` が `caption` を渡すようにした
- `src/scenes/demo.js` の `STRATEGIES` に名前を持たせ、ツールチップを
  `探し方: 機械的` / `探し方: 人間的` に、画面下の説明文を
  `探し方は「機械的」と「人間的」の 2 種類` にした。切り替えのときに名前も差し替える
- `docs/UsersGuide.md` の呼び方を直した（機械的には「深さ優先の探索」と添えた）
- 変えていないもの: URL の `?demo=random|depth`、内部の名前、コメントの中の
  アルゴリズムの説明
