# TODO-005. スマホ横画面ではみ出ないようにする

## きっかけ

スマホ（アプリ内ブラウザ含む）の横画面で遊んだとき、盤面・トレイが
画面の実際に見える範囲より大きく描画され、上下・右端が切れて見える、
という報告をスクリーンショット付きで受けた。

## やったこと

`index.html` の `html, body` の高さ指定を `100dvh`（動的ビューポート
高さ）に直した。`100%` は非対応環境向けのフォールバックとして残し、
`100dvh` を後から上書きする形にした。

アドレスバーなどを含めた分まで高さを大きく見積もる端末があり、
`height: 100%` だとその過大な高さに `#app` が合わせられ、Phaser の
`Scale.FIT` がその大きさに合わせて拡大してしまい、実際に見える範囲を
はみ出していたと見られる。`100dvh` は実際に見えているビューポートの
高さを指すため、これに合わせて `#app` の高さが決まるようにした。

## テスト

実機（スマホ横画面）で見た目を確かめる手段がこの環境になく、
実機での見え方は未確認。公開後に利用者が確認する。
