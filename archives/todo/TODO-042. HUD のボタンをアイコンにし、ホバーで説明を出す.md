## きっかけ

プレイ中の HUD のボタンを分かりやすいアイコンにし、ホバーしたときに説明を出してほしいという依頼。

## やったこと

立てるときに利用者と決めたこと: アイコンは Graphics API で描く（Unicode の記号や
絵文字は OS で形が変わり、色の組とも合わない）。デモの HUD も含める。タッチ端末では
押したときに動作させつつ説明を短く出す。

- `src/icons.js` を足し、12 種のアイコン（一手戻す・おまかせ・ヒント表示・やり直し・
  音 ON／OFF・タイトルへ・ゆっくり・速い・最速・次の解を探す）を線画で描く
- `src/ui.js` の `createButton()` に `icon`（描画関数）と `tooltip`（説明）を足し、
  `setIcon()`・`setTooltip()` を生やした。アイコンの色はボタンの状態（通常・押せない・
  選んである）に連れていく。文字のボタン（タイトル・クリア・記録）は今までどおり
- 説明の枠 `createTooltip()` を 1 シーンに 1 つ作り、シーンの `tooltip` に持たせる。
  ボタンの下に出し、左右は画面の内側に収める。マウスは載せて少し待ってから出し、
  外す・押すと消す。タッチ（`pointer.wasTouch`）は押したあと一定時間だけ出す。
  Canvas の外へ直接出たとき（`gameout`）も消す
- 待ち時間・表示時間・寸法は `config.js` の `TOOLTIP`・`ICON` に置いた
- `README.md`（操作表・デモの節・構成の木）、`docs/developer.md`（画面の用語）、
  `CLAUDE.md`（ファイル構成の表）を合わせた

利用者と決めて、そのままにしたこと:

- 縦画面では 1 段目のボタンの説明が 2 段目のボタンに重なる（一時的な表示なので）
- マウスで音を切り替えたあと、新しい状態の説明は一度外して載せ直すまで出ない
- Canvas の外へ出たとき、ボタンのホバーの見た目は戻さない（戻すと、載り直しても
  Phaser が `pointerover` を出さず、見た目が戻らなくなった。実測）

## 分担の振り返り

- **implementer が見つけたこと**: headless では Phaser の時計が実時間より遅く進むこと
  （確認の担当の待ち時間に効く）。縦画面での説明の重なりと、音の説明が載せ直すまで
  変わらないこと。どちらも利用者の判断に回せた
- **reviewer が見つけたこと**: Canvas の外へ直接出ると説明が残る不具合（実測つき）、
  通る道の無いコード（`refresh()`・`owner`）、README の構成の木とデモの節の漏れ、
  JSDoc の書き方。実装した本人の確認では出てこなかったもので、入れた効果があった
- **screens が見つけたこと**: 問題なし。reviewer の後に回したので、撮り直しは無かった

  見直しで、文書の漏れ（構成の木）は reviewer が拾えた
