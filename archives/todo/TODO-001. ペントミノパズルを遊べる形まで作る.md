# TODO-001. ペントミノパズルを遊べる形まで作る

## きっかけ

リポジトリに `README.md` と `CLAUDE.md` だけがあり、中身が無かった。
8×8 の中央 2×2 を穴にした 60 マスへペントミノ 12 種を敷き詰めるパズルを、
ブラウザで遊べる形まで作る。解は 65 通りあり、1 画面に収まる大きさなのでこの盤面にした。

作り始める前の相談で決めていたこと:

| 項目 | 決定 |
|---|---|
| 土台 | ビルド工程なし。Phaser 3.90.0 を CDN から読み込み、自前コードは ES Modules |
| 盤面 | 8×8 の中央 2×2 を穴 |
| 操作 | ドラッグで配置。掴んでいないときのタップで右 90° 回転、長押しで反転 |
| 補助機能 | Undo / 経過時間とクリア記録 / 置けない場所の警告 / ヒント（1 ピース置く） |
| 効果音 | 入れる（Web Audio で合成。アセットファイルは持たない） |

## やったこと

`index.html` / `tests.html` と `src/` 以下を一通り書いた。分担せず通しで書いた
（ファイル数は多いが 1 つ 1 つは小さく、盤面の座標系と `config.js` の定数を
全ファイルが共有するため）。モデルは Opus / effort high。

### 設計どおりに作ったところ

- `logic.js` — `normalize` / `rotateCw` / `flip` / `orientations` / `boardCells` /
  `canPlace` / `place` / `remove` / `isSolved` / `formatTime`。盤面は書き換えず
  作り直して返す
- `solver.js` — 深さ優先。「空きマスのうち一番若い位置から必ず埋める」と
  「空き領域を連結成分に分け、5 で割り切れない塊があれば切る」の 2 つの枝刈りで足りた
- `game.js` — 盤を左、トレイを右。ドラッグ中は掴んだマスを指の位置に合わせ、
  置ける場所には薄い影を出す。置けなければ赤く光らせて元の場所へ戻す

### 決めたこと・変えたこと

- **求解の打ち切り上限は 1,000,000 回**（立てたときは「実測してから決める」だった）。
  実測は空の盤面が 11,315 回（Node で 15 ms）、最悪が「1 個だけ置いた詰みの盤面」の
  448,217 回（置き方 1568 通りを総当たりした最大値、317 ms）。2 個置くと 92,375 回まで
  下がる。上限を最悪値の倍に取ったので、遊べる盤面はすべて「解ける」か「詰み」かを
  言い切れる。ブラウザでのヒント 1 回目の応答は 190〜280 ms だった
- **I ペントミノの向きは 4 通りではなく 2 通り**。項目を立てたときの記述が誤っていた。
  正しくは X が 1、I が 2、T・U・V・W・Z が 4、F・L・N・P・Y が 8 で、合計 63 通り。
  `tests.html` はこの値で検査している
- **`src/ui.js` を足した**（当初の構成表には無かった）。ボタンと枠を
  タイトル・本編・クリアの 3 シーンが同じ見た目で使うため。`CLAUDE.md` と
  `README.md` の構成表にも足した
- **`index.html` の入れ物の id は `game` にしない。** 要素の id は同名のグローバル
  変数になるので、`src/main.js` が入れる `window.game`（デバッグ用の入口）と衝突する。
  `app` にした
- **`#notice[hidden]` を CSS に明示した。** id 指定の `display: flex` が
  `[hidden]` の `display: none` に勝ってしまい、起動できたのに案内が消えなかった

## テスト

`python3 -m http.server 8765` で確認した。

### `tests.html`

**39 件すべて通った。** 内訳は `config.js` のピース定義が 6 件、`logic.js` の
向きの生成が 9 件、盤面が 14 件、`solver.js` の求解が 10 件。

求解については、設計で挙げた「空の盤面から解が 1 つ求まる」「その解が盤面をちょうど
埋める」「詰みの盤面では解なしを返す」に加えて、上限での打ち切り、盤面を書き換えない
こと、ヒントが一番若い空きマスを覆うことも見ている。

詰みの盤面は「F を左上へ置くと (0,0) が 1 マス取り残される」形を使った。

### ブラウザで通しで遊ぶ

headless の Chromium を CDP で操作して、次の 24 項目を確かめた（すべて通り、
コンソールにエラーは出なかった）。

タイトルが出る / 案内が消える / 本編へ移る / ドラッグで置ける / 空きマスが減る /
履歴が増える / ドラッグ中に影が出る / 影の場所に置かれる / 重なる場所には置けず戻る /
理由が出る / 置けなかった手は履歴に積まない / タップで回転 / 長押しで反転 /
X は形が変わらない / 盤からドラッグして外せる / 外した手も履歴に積む /
一手戻すと盤へ戻る / もう一手戻すとトレイへ戻る / やり直しで最初に戻る /
ヒントを押し続けるだけで完成する / Clear へ移る / 記録が保存される / もう一度で本編へ戻る

**確認に使った操作の注意**: headless Chromium では CDP の
`Input.dispatchMouseEvent` が投げる `mousemove` / `mouseup` が Phaser まで届かず、
ドラッグがまったく動かないように見える。ページ側で `MouseEvent` を組み立てて
canvas へ `dispatchEvent` すると正しく動く（Phaser 3 は `pointerdown` ではなく
`mousedown` / `mousemove` / `mouseup` を見ている）。この件でしばらく本体の不具合を
疑ったので書き残す。
