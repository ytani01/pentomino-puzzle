# TODO-020. ヒント使用時は記録に残さない

## きっかけ

記録に残すのは、すべて自力で解いたときだけにしたい。対象は、今ある盤ごとの
最短時間と、008 で作った履歴の両方。求解に頼る操作はどれも「自力ではない」
と見なすので、ヒント（`game.js` の `usedHint`）に加えて 013 の「解の有無を
教えるモード」（`usedCheck`）も含める。

`clear.js` は今まで、ヒントを使っても最短時間を更新し、「ヒントを使った」と
添えるだけになっていた。この判断を変えることにした。

## やったこと

- `storage.js` に `shouldRecord(usedHint, usedCheck)` を足した。ヒント・
  詰み表示のどちらかを使っていたら `false` を返す純関数。
- `clear.js` の `create()` で、`shouldRecord()` が `false` のときは
  `saveBest()` / `addHistory()` を呼ばず、最短時間の表示は `loadBest()` で
  読むだけにした（更新はしない）。
- 記録が残らないときの見せ方を書き直した。「〜の最短 mm:ss（今回は記録
  しない）」、記録がまだ無ければ「〜はまだ記録が無い（今回も記録しない）」
  と出す。ヒント・詰み表示を使ったこと自体は、これまでどおり別の行に出す。
- 「求解に頼ったかどうかは、記録の扱いを変えるほどではないが伝えておく」
  というコメントは、判断を変えたので書き直した。

## テスト

`tests.html` に `shouldRecord()` の組み合わせ（両方 false / ヒントのみ /
詰み表示のみ / 両方）を確かめるテストを足した。131 件すべて通った
（headless Chromium で確認）。
