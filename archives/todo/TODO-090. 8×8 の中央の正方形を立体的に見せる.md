## きっかけ

利用者の依頼。中央の 2×2 の穴に嵌めたアクリルの板が平たく見えるので、立体的に見せる。
見せ方は「縁の明暗」（上と左を明るく、下と右を暗く）に利用者と決めた。影は周りのマスに
かかるので付けない。

## やったこと

- `src/ui.js` の `drawAcrylic()`: 右と下だけにあった細い厚み（3px の矩形）を、4 辺の
  台形の面取りに替えた。上と左は `ACRYLIC.edge` で明るく、下と右は `TILE.shadow` で暗く塗る。
  内側の細い線は面取りの内端に引く
- 面取りの幅は板の短い辺に対する割合（`ACRYLIC.bevel = 0.08`）にした。記録の完成形は
  盤が小さく、固定の幅では面取りが板を覆うため
- `src/config.js` の `ACRYLIC` から `innerInset` / `thickness` / `thicknessAlpha` を外し、
  `bevel` / `bevelLightAlpha` / `bevelDarkAlpha` を足した

## 確かめたこと

- screens が本編（1280×720・844×390）と記録の完成形（844×390）を撮って確かめた。
  明暗の向き、板の外へのはみ出しなし、小さな盤でも覆い過ぎない、コンソールのエラー 0 件
  （[報告](../agents/TODO-090/screens-report.md)）
- main も本編の切り抜きを見て、板が浮き出て見えることを確かめた
