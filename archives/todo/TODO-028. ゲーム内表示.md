# TODO-028. ゲーム内表示

## きっかけ

用語とダイアログの表示を見直したかった。

- 「詰み表示」は否定的な言い方で、何をする機能なのか（残りのピースで
  最後まで置けるかを教える）が名前から伝わらない
- 「ヒント」は 1 手だけ置く機能だが、名前からは「助言が出る」ように読める
- 確認ダイアログの二択が、画面ごとに「戻る／やめる」「消す／やめる」と
  まちまちだった

## 決めたこと

| 場所 | 前 | 後 |
|---|---|---|
| ゲーム画面のボタン | ヒント | **おまかせ** |
| ゲーム画面のボタン | 詰み表示 | **ヒント表示** |
| クリア画面の「頼った」表示 | ヒント / 詰み表示 | おまかせ / ヒント表示 |
| 記録一覧の印 | ヒント / 詰み | おまかせ / ヒント |
| タイトルへ戻る確認 | 戻る / やめる | **はい / いいえ** |
| 記録を消す確認 | 消す / やめる | **はい / いいえ** |

「ヒント」の案は初め「自動」だったが、**1 手しか置かない**のに全部やって
くれるように読めるので「おまかせ」にした。

二択を「はい／いいえ」に揃えるにあたっては、「消す」のような**取り返しの
つかない操作は動詞のままのほうが結果を読み違えにくい**という懸念を伝えた
うえで、統一を選んだ。どちらのダイアログも本文が疑問文なので、何に対する
「はい」かは読めば分かる。

## やったこと

**表示だけでなくコード内の識別子も揃えた**（利用者の指示）。`ヒント` の
指すものが入れ替わるので、機械的な置換ではなく 2 段階で付け替えた。

| 概念 | 表示 | 識別子 | 保存キー | 履歴の印 |
|---|---|---|---|---|
| 1 手だけ置く | おまかせ | `auto`（`usedAuto` / `autoFrom()` / `useAuto()` / `loadAuto()`…） | `pentomino-puzzle/auto/<盤>`（前は `hinted`） | `a`（前は `h`） |
| 解の有無を教える | ヒント表示 | `hint`（`usedHint` / `toggleHint()` / `runHint()` / `hintState`…） | — | `h`（前は `c`） |

触ったファイル: `src/config.js`・`src/solutions.js`・`src/storage.js`・
`src/audio.js`・`src/scenes/game.js`・`src/scenes/clear.js`・
`src/scenes/records.js`・`tests.html`・`README.md`・`docs/developer.md`・
`CLAUDE.md`。

- **`historyKey` の値に `v2` を入れた**（`pentomino-puzzle/history/v2/<盤>`）。
  印の `h` が指すものが入れ替わる（前はおまかせ、今はヒント表示）ので、
  前の版が書いた件をそのまま読むと**印の意味がずれる**。キーを変えて
  読まないようにしてある。**保存済みの記録は消えてよい**と利用者が判断した
- `clear.js` の `PANEL_ROWS.hint` は `help` にした。「何に頼ったか」を出す
  行で、ヒント表示の行ではないため
- `checkSolved()`（解けたかを判じる）は名前を変えていない。ヒント表示とは
  関係のない処理なので
- 「詰み」という語自体は、**盤面の状態**を指す語としてコメントとテスト名に
  残してある（画面には「解なし」と出る）。ボタン名としての「詰み表示」だけを
  改めた
- `docs/developer.md` の「画面の用語」に**おまかせ**と**ヒント表示**の行を足した
