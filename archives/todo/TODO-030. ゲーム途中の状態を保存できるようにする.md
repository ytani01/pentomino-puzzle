# TODO-030. ゲーム途中の状態を保存できるようにする

8×8・6×10 それぞれ別に保存できるようにする、というのが立てたときの条件。

## きっかけ

途中で用ができてタイトルへ戻ると、そこまでの盤面と時間が消えていた。
`タイトルへ戻りますか？` の確認にも「今の進み方は失われます」と書いてあり、
中断のたびに最初からやり直すことになっていた。

## 決めたこと（利用者と相談）

- **再開の入口は `つづきから`。** タイトルに `はじめる` と並べて置く。
  「はじめるが自動で続きになる」案は、押すまで何が起きるか分からないので採らない
- **一手戻す履歴は保存しない。** 最大 60 手ぶんの盤面とピースの配置になり、
  保存する量も検証も一気に膨らむ。再開した直後だけ戻せない不便さと引き換えにした

## やったこと

### 保存する形（`src/storage.js`）

```
{ ms, usedAuto, usedHint, pieces: [{ name, cells, location, row, col } × 12] }
```

- **盤面（`board.grid`）は持たない。** ピースの位置から組み直せるうえ、盤面まで
  別に持つと、手で書き換えられたときに 2 つの食い違いをどう扱うかを決めることに
  なる。ピースだけなら `canPlace()` で置けるかを見るだけで済む
- `usedAuto` / `usedHint` を持ち越すのは、**中断で印を消せてしまうと最短時間の
  意味が無くなる**ため（TODO-020 の判定）
- 保存先は盤ごと（`BOARDS[key].progressKey`）。8×8 を遊びかけたまま 6×10 を
  始めても、どちらの続きも残る

`sanitizeProgress()` は**1 か所でも辻褄が合わなければ丸ごと捨てる**。履歴は
1 件ずつ独立しているので壊れた件だけ捨てられるが、こちらは 12 個で 1 つの盤面
なので、一部だけ通すと遊べない盤面（同じ升へ 2 個、知らない向き）が出来てしまう。
見るのは「12 種が 1 個ずつ」「`cells` がそのピースの向きのどれか
（`orientations()` と照合）」「盤の分が重ならず収まる（`canPlace()`）」
「12 個とも盤に載っていない（＝完成した盤面には続きが無い）」の 4 つ。

`saveProgress()` は使えない値なら**保存せずに消す**。古い遊びかけが残って、
続きから始めたときに前の盤面が出るのを防ぐため。

### 控える時機（`src/scenes/game.js`）

- 盤が変わったところ（`refreshHud()`）。置く・外す・向きを変える・戻す・
  おまかせのどれもここを通る
- シーンを離れるとき（`shutdown`）。置いてから何分も考えて中断すると、
  その考えていた時間が落ちてしまうため
- **組み立ての最中は控えない**（`this.ready`）。まだ何も置いていない状態で
  保存してしまうと、`はじめる` を押し間違えただけで前の遊びかけが消える
- 1 個も置いていないときは控えずに消す。`つづきから` が「はじめから」と
  同じ意味になるだけで、押せるボタンが増えたぶん紛らわしい
- 解き切ったとき（`checkSolved()`）と `やり直し`（`restart()`）では消す。
  どちらも先に `playing` を偽にして、離れるときの控えが書き戻さないようにする
- `やり直し` は `scene.restart({ resume: false })`。引数を渡さないと `init()`
  が前の `resume` を受け取り、続きから始め直してしまう

### 画面

- タイトルは行を足さず、`はじめる` と `つづきから` を**同じ行へ横に並べた**
  （260 幅 × 2 + 間 20 = 540）。行を足すと横画面（内部解像度 640）の縦が
  足りない（`title.js` の `STACK` の説明）
- 遊びかけが無い盤では `つづきから` を押せなくする。隠さないのは、盤を選び直す
  たびにボタンが出たり消えたりして行が動くため（記録の画面の `消す` と同じ見せ方）
- `タイトルへ戻りますか？` の確認から「今の進み方は失われます」を消し、
  `つづきから` で再開できると伝える文にした

## テスト

`tests.html` に 15 件足した（盤ごとの分と合わせて 31 件増え、**235 件すべて通る**）。

- `sanitizeProgress` … 正しい遊びかけを通す／JSON の文字列でも読める／
  12 個とも盤・同じピースが 2 つ・無い向き・重なり・はみ出し・経過時間が
  数でない・12 個でない、をそれぞれ捨てる／印は真のときだけ持ち越す
- `saveProgress` と `loadProgress` の往復、`clearProgress`、使えない値を渡すと
  前のものごと消える、記録（履歴・達成度）を消しても遊びかけは残る

ブラウザでも通しで確かめた（CDP から本物の操作の道筋を通して実行）。

- おまかせで 3 個置く → タイトルへ戻る → `つづきから` で**盤面の 60 マスが
  一致**し、経過時間とおまかせの印も引き継がれ、一手戻す履歴は空
- 8×8 の遊びかけがあるとき、盤を 6×10 へ切り替えると `つづきから` が押せなくなる
- `やり直し` のあとは遊びかけが消え、盤に置かれたピースが 0 になる

見た目は横 568×320 と縦 375×667 で撮り、2 ボタンが収まること、
確認の枠の 3 行が枠に収まることを確かめた。
